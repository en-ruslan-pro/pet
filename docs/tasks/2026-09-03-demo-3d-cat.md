# Первый этап Virtual Pet TV: живая 3D-кошка

## Цель

Реализовать страницу `/demo` с самостоятельной 3D-кошкой в комнате, камерой, освещением и циклом действий `Idle`, `Walk`, `Sit`.

## Ограничения и критерии готовности

- Использовать стек, совместимый с Laravel и Vite.
- Кошка должна самостоятельно выбирать и выполнять действия без сервера состояния.
- Добавить Feature-тест маршрута и запустить затронутые проверки с `.env.testing`.
- Для полноценного WebGL-рендеринга требуется подтверждение добавления Three.js, поскольку этой зависимости в проекте пока нет.

## Этапы работы

1. **Готово:** изучены маршруты, фронтенд-сборка, зависимости и правила тестирования.
2. **Готово:** установлен Three.js и реализована страница `/demo` с 3D-комнатой, процедурной моделью кошки и автономным циклом действий.
3. **Готово:** Feature-тест прошёл, PHP отформатирован, production-сборка Vite выполнена успешно.

## Результат

- Добавлен маршрут `/demo` и самостоятельная полноэкранная TV-сцена.
- Мурка плавно переключается между состояниями `Idle`, `Walk` и `Sit`; при прогулке выбирается одна из случайных точек комнаты.
- Использована оптимизация для TV: ограничение device pixel ratio до 1.5 и аппаратно-предпочтительный WebGL-рендерер.
- До появления утверждённого GLB-ассета используется процедурная low-poly модель кошки.
- Проверки: `vendor/bin/pest tests/Feature/DemoTest.php --compact` — успешно; `npm run build` — успешно; `vendor/bin/pint --dirty --format agent` — успешно.

## Замена модели

- Получен пользовательский GLB-файл `stripe_the_cat_rigged_and_animated.glb`.
- Готово: процедурная модель заменена на GLB Stripe; встроенный клип `All Animations` используется как fallback для автономных состояний, поскольку файл не содержит отдельных клипов `Idle`, `Walk` и `Sit`.
- Добавлена обязательная атрибуция DreamNoms по лицензии CC BY 4.0.
- Проверки после замены: GLB распознан как glTF 2.0; `npm run build`, `vendor/bin/pest tests/Feature/DemoTest.php --compact` и `vendor/bin/pint --dirty --format agent` завершились успешно; визуальная проверка `/demo` не выявила ошибок браузера.

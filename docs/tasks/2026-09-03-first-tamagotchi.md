# Первый Tamagotchi — Version 0.3

## Цель

Добавить постоянные показатели голода, энергии и настроения, а также действия кормления, игры и сна из контроллера комнаты.

## Ограничения и критерии готовности

- Значения находятся в диапазоне 0–100 и сохраняются в комнате.
- С течением времени голод растёт, энергия и настроение снижаются.
- Каждое действие изменяет показатели и передаётся на телевизор через существующий канал комнаты.

## Этапы работы

1. **Готово:** изучены план, текущая модель комнаты, realtime-канал и правила тестирования.
2. **Готово:** добавлены постоянные показатели, контроллерные действия и реакции сцены.
3. **Готово:** добавлены Feature-проверки действий, сохранения показателей, их изменения со временем и запрета доступа без сессии комнаты.

## Результат и проверка

- Изменённые области: модель и миграция `rooms`, контроллер и маршруты комнаты, realtime-команды, контроллерный интерфейс, 3D-сцена и Feature-тесты.
- Миграция безопасна для существующих комнат: показатели имеют значения по умолчанию, а метка времени обновления допускает `NULL`; расчёт начинает отсчёт при первом обращении.
- Проверки: `APP_ENV=testing vendor/bin/pest tests/Feature/RoomTest.php tests/Feature/DemoTest.php --compact` — 11 тестов успешно; `vendor/bin/pint --dirty --format agent`, `npm run build` и `git diff --check` завершились успешно.
- Ограничение: показатели меняются в момент принятия команды сервером. Подтверждение завершения сценария с TV и жизненный цикл `Requested → Started → Finished` остаются задачей следующего realtime-этапа.

## Исправления после браузерной проверки

- **Готово:** исправлен устаревший текст про QR-код — подключение TV описывается через ручной ввод кода комнаты.
- **Готово:** обновление показателей и отправка realtime-команды выполняются в одной транзакции. Если Reverb недоступен, состояние питомца не изменяется.
- Добавлены Feature-проверки обоих случаев.

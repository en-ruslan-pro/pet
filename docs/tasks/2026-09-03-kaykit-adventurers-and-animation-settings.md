# KayKit Adventurers и настройки анимаций

## Цель

Проверить лицензию пакетов KayKit, добавить бесплатных персонажей Adventurers в каталог сайта и дать администратору выбор активных анимаций для каждого персонажа.

## Ограничения и критерии готовности

- Используются только бесплатные модели из официального публичного репозитория KayKit Adventurers.
- Лицензия CC0 1.0 подтверждена на страницах автора и сохранена рядом с ассетами.
- Все доступные анимации нового персонажа включены по умолчанию; Filament позволяет отключать отдельные.
- TV отображает выбранного для комнаты персонажа и не запускает отключённые клипы.

## Этапы

1. **Готово:** проверена лицензия, получен официальный бесплатный набор из пяти GLB-моделей.
2. **Готово:** каталог, настройка анимаций и TV-интеграция.
3. **Готово:** автоматические проверки, статический анализ и production-сборка фронтенда.
4. **Готово:** выбранный персонаж передаётся в начальный URL 3D-сцены, без промежуточной загрузки кошки.
5. **Готово:** на странице `/demo` добавлен выбор персонажа; список анимаций обновляется после смены модели.
6. **Готово:** production-deploy запускает `PetCatalogSeeder` после миграций.

## Результат и проверка

- В `public/models/kaykit-adventurers` добавлены бесплатные GLB: Barbarian, Knight, Mage, Rogue и Rogue Hooded, а также исходный `LICENSE.txt` CC0 1.0.
- `PetCatalogSeeder` создаёт пять персонажей, их 3D-модели, 76 встроенных клипов и соответствующие конфигурации. Все 76 клипов активны по умолчанию.
- В справочник Filament добавлен список включённых анимаций. При выборе другой 3D-модели список заполняется всеми её доступными клипами; администратор может отключить отдельные или все сразу.
- TV передаёт выбранную для комнаты модель в 3D-сцену и фильтрует клипы по настройкам персонажа. Старые комнаты и персонажи без конфигурации продолжают использовать все клипы модели.
- При обновлении TV-комнаты сцена сразу запрашивает выбранную модель из стартового URL. Последующее сообщение синхронизации не вызывает повторную загрузку той же модели.
- На `/demo` список персонажей формируется из каталога; после выбора загружается связанная модель и выпадающий список содержит только включённые для неё клипы.
- Базовая модель полосатой кошки в сидере указывает на фактически добавленный файл `stripe-the-cat.glb`, поэтому её также можно безопасно выбрать в демо.
- Production workflow вызывает `php artisan db:seed --class=PetCatalogSeeder --force` сразу после миграций; сидер идемпотентен благодаря `updateOrCreate`.
- Лицензия: обе страницы автора указывают CC0 1.0, свободное личное и коммерческое использование без обязательной атрибуции. Взята только бесплатная часть Adventurers; три Extra-персонажа не добавлялись.
- Проверки: до исправления загрузки `APP_ENV=testing vendor/bin/pest --compact tests/Feature/RoomTest.php tests/Feature/PetDataFoundationTest.php tests/Feature/Filament/DostupPanelAccessTest.php` — 27 тестов успешно; после него — новый тест TV-конфигурации персонажа успешно. Для выбора на демо: `APP_ENV=testing vendor/bin/pest --compact tests/Feature/DemoTest.php` — 6 тестов успешно. `vendor/bin/pint --dirty --format agent`, `./vendor/bin/phpstan analyse --memory-limit=512M`, `npm run build` и `git diff --check` завершились успешно.
- Ограничение: отдельный пакет Character Animations не имеет публичного прямого архива в официальном репозитории; текущие 76 встроенных клипов моделей уже настраиваются. После предоставления GLTF-файлов отдельного пака их можно зарегистрировать в этой же конфигурации.

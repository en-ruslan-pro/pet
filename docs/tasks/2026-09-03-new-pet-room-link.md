# Ссылка в комнату после создания питомца

## Цель

После создания питомца показать на открывшемся контроллере прямую ссылку в его TV-комнату.

## Критерий готовности

- На странице созданной комнаты видна ссылка «Открыть комнату».
- Ссылка ведёт на TV-комнату созданного питомца.

## Этапы

1. **Готово:** добавлена прямая ссылка на TV-комнату в контроллере.
2. **Готово:** Feature-проверка подтверждает текст и адрес ссылки; форматирование и проверка diff завершились без ошибок.

## Результат и проверка

- Изменённые области: контроллерная страница комнаты и её Feature-тест.
- Проверки: `APP_ENV=testing vendor/bin/pint --dirty --format agent`, `APP_ENV=testing vendor/bin/pest tests/Feature/RoomTest.php --compact` — 16 тестов успешно; `git diff --check` — без ошибок.

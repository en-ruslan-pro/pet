# Удаление кроватки и окна из комнаты

## Цель

Убрать из 3D-комнаты кроватку и процедурно генерируемое окно по запросу пользователя.

## Критерии готовности

- В сцене не загружается модель кроватки.
- В сцене не создаётся окно и нет поведения, ведущего питомца к нему.
- Документация состава комнаты соответствует сцене.

## Этапы работы

1. **Готово:** удалены GLB-модель кроватки, процедурное окно и связанные точки взаимодействия.
2. **Готово:** автономное наблюдение у окна и привязка сна к удалённой кроватке убраны; сон выполняется на текущем месте.
3. **Готово:** целевые Pest-тесты и production-сборка фронтенда успешно завершены.
4. **Готово:** расстановка вынесена в конфиг, а маршрут строится через свободную область комнаты.

## Результат и проверка

- Изменённые области: `resources/js/demo.js`, `docs/assets/room-models.md` и `tests/Feature/DemoTest.php`.
- Из сцены удалены загрузка `simple_single_bed`, процедурная группа окна, их точки взаимодействия и автономное действие наблюдения у окна.
- Сон больше не направляет питомца к удалённой кроватке и выполняется на текущем месте.
- Проверки: `APP_ENV=testing php artisan test --compact tests/Feature/DemoTest.php` — 3 теста успешно; `npm run build` — успешно; `git diff --check` — без ошибок.
- Ограничение: визуальный ручной прогон `/demo` в браузере не выполнялся.

## Конфигурация расстановки и маршрутов

- Все предметы комнаты описаны в `resources/js/room-layout.js`: позиция, габариты, модель или процедурный объект и правило `catCanEnter`.
- Блокирующие предметы участвуют в проверке пересечений и расширяются на радиус кошки при поиске пути. Ковёр, миски, мяч и игрушечная мышь разрешают кошке заходить на их поверхность.
- Добавлен A*-поиск пути по сетке свободной области; кошка проходит между мебелью, а не движется через неё напрямую.
- Проверки: `APP_ENV=testing php artisan test --compact tests/Feature/DemoTest.php` — 4 теста успешно; `npm run build` — успешно; отдельная проверка маршрута до миски вернула 12 безопасных точек.

## Проверка пересечений предметов

- Тест расстановки теперь проверяет пересечения всех предметов комнаты, независимо от правила проходимости для кошки.
- Только мяч и игрушечная мышь имеют явную пометку `allowsItemOverlap`, так как намеренно лежат на ковре; любое другое пересечение приводит к падению теста.

## Диагональное движение

- Поиск пути поддерживает восемь направлений, поэтому кошка может ходить по диагонали.
- Диагональный шаг запрещён, если он срезает угол через предмет; тест подтверждает наличие безопасного диагонального сегмента.

## Расстановка когтеточки

- Когтеточка перенесена к задней стене; точка взаимодействия расположена перед ней, вне её габаритов и зоны коллизии кошки.

# План: шаги анимаций модели и игровые действия

## Цель

Сделать конфигурацию анимаций модельно-зависимой: сначала сопоставлять внутренние шаги с точными GLB-клипами модели, затем собирать из этих шагов последовательные игровые действия.

## Критерии готовности

- У модели настраиваются активные внутренние шаги и несколько вариантов клипов для каждого шага.
- У варианта клипа есть вес для случайного выбора и параметры воспроизведения.
- Игровое действие представляет собой упорядоченную последовательность шагов и может быть отключено для модели.
- Filament позволяет настроить обе сущности без ручного редактирования JSON.
- TV получает итоговую конфигурацию и не подбирает клипы эвристически по имени.

## Этапы

1. **Готово:** добавлены таблицы и модели для системных шагов, активных шагов модели, вариантов клипов и упорядоченных шагов игрового действия.
2. **Готово:** добавлены Filament-ресурсы «Внутренние шаги», «Игровые действия» и «3D-модели». В модели редактируются активность, клипы, веса, скорость и зацикливание.
3. **Готово:** игровой сценарий настраивается вложенным упорядоченным списком внутренних шагов; у действия и шага есть независимая активность.
4. **Готово:** TV получает активную конфигурацию, последовательно исполняет шаги и выбирает клип по весу. Старые поля выбора клипов у персонажа и JSON-сопоставление действий удаляются миграцией.
5. **Готово:** добавлены Pest-тесты конфигурации, исключения неактивных шагов, TV-передачи конфигурации и Filament-формы.
6. **Готово:** в Filament добавлены настройки автономности, веса, длительности и эффектов потребностей игрового действия, а также цели комнаты и диапазона длительности для конкретной модели.

## Принятые решения

- Игровое действие, например `sleep`, — внешний сценарий. Его внутренние шаги, например `sleep.start`, `sleep.loop` и `sleep.finish`, исполняются строго в заданном порядке.
- Один шаг модели может иметь несколько активных клипов. TV выбирает вариант случайно, пропорционально его весу.
- Активность задаётся и у игрового действия, и у внутреннего шага, чтобы отключать лишние возможности для конкретной модели.
- Стартовый каталог создаётся через `DatabaseSeeder`; для чистой базы используется `php artisan migrate --seed`, а не запуск сидера из миграции.

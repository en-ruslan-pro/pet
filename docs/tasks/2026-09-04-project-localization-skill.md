# Правило локализации внешнего текста

## Цель

Добавить проектный навык, который требует хранить весь пользовательский текст в английских и украинских языковых файлах Laravel и определять язык по настройкам браузера с английским запасным языком.

## Критерии готовности

- Навык автоматически применяется при изменении внешнего текста.
- В нём зафиксированы оба обязательных языка и использование языковых файлов.
- Для неизвестного или отсутствующего языка браузера указан английский вариант.

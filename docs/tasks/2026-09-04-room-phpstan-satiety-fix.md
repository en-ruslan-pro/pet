# Исправление PHPStan для сытости комнаты

## Цель

Устранить ошибку PHPStan при расчёте голода после действия питомца.

## Критерии готовности

- Расчёт после кормления сохраняет прежний результат.
- PHPStan не сообщает об избыточном запасном значении для `satiety`.

## Этапы

1. **Готово:** удалено недостижимое запасное значение для обязательного ключа `satiety`.

## Изменённые области

- `app/Models/Room.php` — расчёт голода после действия питомца.

## Проверки

- `vendor/bin/pest tests/Feature/RoomTest.php tests/Feature/DemoTest.php --compact` — 41 тест успешно.
- `vendor/bin/pint --dirty --format agent` и `vendor/bin/phpstan analyse` — успешно.
